## По работам

**Шаблон** — перекодировка кириллицы таблицами. Аккуратно, без внешних библиотек.

**ДЗ 2** — скачивание JSON через curl, разбор cJSON, вывод погоды. Динамический буфер (`realloc` в колбэке) — тот же паттерн, что у рендерера страниц: буфер живёт, пока его явно не освободят.

**ДЗ 3** — явно про утечки: `free_list` после фильтра. Прямой предшественник финальной темы.

**ДЗ 4** — не «написать 100 строк», а разобрать большой C-проект (curl). Финалка в том же жанре: читать Zathura, а не писать viewer с нуля.

**clib / ДЗ 5** — ещё один чужой репозиторий, зависимости, сборка.

**ДЗ 6** — GTK. Zathura тоже GTK + cairo. Без этой работы смотреть `page-widget.c` было бы заметно тяжелее.

**ДЗ 7** — аккуратная работа с ресурсами (файл лога, мьютекс, символы стека).

**ДЗ 8–12** — процессы, сокеты, HTTP. Для Zathura это фон, не инструмент поиска бага.

**ДЗ 13** — strace. Для утечки нужен другой инструмент (valgrind / ASan), но привычка смотреть, что процесс реально делает, та же.

**ДЗ 14** — кольцевой буфер ограниченного размера с вытеснением. Кэш страниц Zathura — ровно это, только элементы не байты, а cairo-поверхности. Если вытеснил слот и не освободил payload — буфер «ограничен», а память нет.

**ДЗ 15–17** — SQLite и графика. OpenGL в 16–17 ближе к «держим текстуру, пока не `glDeleteTextures`»; cairo surface — тот же класс ошибок.

## Почему не другие темы финалки

- **dwm / spectrwm, произвольное число панелей.** Это X11, геометрию монитора, `Bar`/`Monitor`, события. В семестре оконных менеджеров не было. Плюс готовые патчи (`barmodules`, `extrabar`) огромные — легко скатиться в копипасту.
- **Плагин mpd + стриминг.** Нужны plugin API mpd, декодер, HTTP и конкретный сервис с ключами. Это уже отдельный курс, не «базовый C».
- **Утечка в Zathura при скролле PDF.** Средняя сложность: один жизненный цикл объекта (поверхность страницы), код локализован в `page-widget.c` / `render.c`, проверяется моделью кэша и valgrind. Пересекается с ДЗ 3, 6, 14.

## Вывод

По семестру видно движение «свой код → чужой большой проект → ресурсы и их срок жизни». Финальная работа продолжает эту линию: найти, где чужой кэш забывает `free`, и закрыть дыру маленьким патчем, а не новым приложением.
