# Модель кэша страниц

Повторяет порядок операций Zathura при скролле:

1. страница попала во вьюпорт → выделить «поверхность»;
2. положить индекс в LRU-кэш (если кэш полон — вытеснить старую);
3. только потом обновить флаги visible.

В исходном коде вытесненная страница не отдаёт поверхность, пока `visible == true`. Флаг обнуляется уже после вытеснения, повторного free нет.

```text
make
./page_cache_scroll        # утечка, код 2
./page_cache_scroll --fix  # live ≈ размер кэша
```
